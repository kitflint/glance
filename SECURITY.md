# Security

This source targets Windows x64 and a selected local NTFS board directory. The visual host binds to loopback and uses a private launch link and authenticated browser session. Keep both private. Other processes with the same Windows user and direct disk or browser access can read or alter local data. See [Privacy](docs/PRIVACY.md) and [Compatibility](docs/COMPATIBILITY.md) for the current scope and limits.

GitHub metadata ships unset. Access to a live App or repository, named assistant-client setup and public release are pending separate verification.

## Reporting

Private vulnerability reporting is pending setup. Keep vulnerability details, credentials, launch links, private board data, unpublished repository details and raw private logs out of public issues. The ordinary bug form is for non-sensitive problems that you can reproduce with synthetic data. Review any logs before attaching them.
